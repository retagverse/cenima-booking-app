# Cinema Ticket Booking System

## Project Description
This is a console-based cinema ticket booking system written in C++. The program displays a menu of 5 movies, allows users to select a movie and the number of tickets, and calculates the total booking cost.

## Features
- Display available movies and ticket prices
- Book up to 10 tickets per transaction
- Automatic total cost calculation
- Input validation
- Multiple bookings in one session
- Booking statistics and revenue tracking

## Technologies Used
- C++
- Functions
- Arrays
- Loops
- Input Validation

## How to Run
1. Open the project in Visual Studio.
2. Build and run the program.
3. Follow the on-screen instructions to book tickets.
